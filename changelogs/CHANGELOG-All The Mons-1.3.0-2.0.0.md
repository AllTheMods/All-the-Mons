# Changelog

# 📦 2.0.0

## 📰 General changes and notes

2.0.0 moves the pack to **Cobblemon 1.8**. Cobblemon now sizes Pokémon itself, has its own TMs (SimpleTMs is gone), and every addon has been updated to match. 
Existing TMs will go poof or turn into Blank TMs from Cobblemon, there is nothing you can do to save them, the same goes for TM Machines.

NeoForge updated to 21.1.265.
